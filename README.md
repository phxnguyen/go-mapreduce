# go-mapreduce

An implementation of Lab 1 (MapReduce) from MIT's [6.824/6.5840 Distributed Systems](http://nil.csail.mit.edu/6.824/2021/labs/lab-mr.html) course (Spring 2021).

The starter code — `mr/`, `mrapps/`, `main/mrcoordinator.go`, `main/mrworker.go`, `main/mrsequential.go`, `main/pg-*.txt`, and `main/test-mr*.sh` — comes from the course's official skeleton; the coordinator/worker RPC logic in `mr/` is the part implemented here.
